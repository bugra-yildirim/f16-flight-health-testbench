# Decisions and open gates

- 2026-09-29: Windows 10 is the first development and FlightGear host. Visual Studio Community 2026 (18.10.12217.157), MSVC 19.51.36260 x64, bundled CMake 4.3.1-msvc1 and Ninja were observed in the user's Developer PowerShell; SDK directory 10.0.26100.0 was observed. Debug and Release configure/build/run subsequently succeeded on that machine.
- 2026-09-29: Use C++17 with Ninja Debug/Release presets. Developer PowerShell supplies `cl`, `cmake`, and `ninja`; do not change the global PATH. Docker and WSL are not prerequisites for the local GUI, joystick, and UDP route.
- 2026-09-29: Use a project-specific Conda environment named `f16-health` with Python 3.12 and pip. Python 3.12.14 and pip 26.2.1 were verified from its path; VS Code integrated PowerShell used it after manual activation. The Select Interpreter screenshot confirmed f16-health (3.12.14) on 2026-09-30. Do not install ML/GPU/UI dependencies for the baseline.
- 2026-09-29: FlightGear 2024.1.7 binaries are installed at `C:\Program Files\FlightGear 2024.1\`; active `Protocol` is in the downloaded `fgdata_2024_1`. The repository protocol and installed copy matched by SHA-256. The addon `f16b52.xml` hash is recorded in [environment acceptance](environment-acceptance.md); local README says 3.83, but exact installed revision is unknown. The addon is not vendored. Its LICENSE is GNU GPL v2 text; inspect individual licensing and attribution before derived aircraft work.
- 2026-09-29: P01 setting 5 yielded about 10 distinct timestamps/s in one trial; this environment trial with setting 5 yielded 20/3.84 s (about 5.2 packets/s), all with distinct advancing timestamps. Treat output cadence as measured run metadata, not a universal mapping from configuration.
- 2026-09-29: Public GitHub visibility was selected. The user corrected the initial MIT choice: original repository files use PolyForm Noncommercial License 1.0.0 with a `Required Notice` for 2026 Halit Buğra Yıldırım. Public access does not mean unrestricted commercial use. The separately installed GPL v2 F-16 addon is not redistributed or relicensed. Attribution and license handling for any later modified aircraft files remain a publication gate. Keep this repository separate from the turbofan projects.
- P04 gate: The proposed partial left flaperon authority fault is not implemented. It must change the model's aerodynamic response under controlled comparison before a physics-affecting fault is claimed. The installed model combines left/right effects; no real single-surface F-16 fidelity claim follows.
- Independent headless JSBSim equivalence, ML/ONNX, CUDA, and final UI technology are future decisions supported by evidence, not baseline dependencies.
